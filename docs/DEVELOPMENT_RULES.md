# Development Guidelines

## How to work
- Understand the task before changing code.
- Inspect the existing codebase.
- Follow the existing code style and architecture.
- Ask questions if something important is unclear.
- Keep changes small and simple.
- Do not implement features that were not requested.
- If requirements are unclear or conflict with the code, ask before making significant changes.

## Communication
- Explain your plan briefly before a significant change.
- Summarize changed files and any remaining issues.
